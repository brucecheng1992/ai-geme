# Step 11A — Non-Default Runtime Integration Gate

Status: current docs-only gate. Step 10B branch boundary has been closed by fast-forward merge into `main`, and this step runs on `docs/art-asset-step-11a-runtime-integration-gate`.

## Goal

Define whether and how a future runtime canary may consume the small art library runtime-safe metadata artifact behind an explicit non-default flag.

## Gate Decision

Proceed to Step 11B only as a non-default canary. Step 11B may introduce a test-only/runtime-canary flag named:

```txt
ASSET_RUNTIME_METADATA_CANARY=small-library-v0.1
```

Default behavior remains equivalent to the current runtime when the flag is absent or empty.

## Flag Contract

- Default state: off.
- Allowed on value: `small-library-v0.1`.
- Any other non-empty value must fail closed with a deterministic diagnostic or usage error.
- The flag must never select a production/default asset pack.
- The flag must never read the large art library.
- The flag must never enable repair writeback.
- The flag must not be consulted by default canary, default project generation, default Workbench, or production runtime paths.

## Input Contract

Step 11B may only consume runtime-safe metadata derived from:

```txt
tests/fixtures/art-library-small-v0.1/metadata
```

The accepted runtime artifact must be generated by the existing runtime-safe export path and must preserve:

- `runtime_metadata_version`;
- deterministic `asset_count=10`;
- relative fixture asset and thumbnail paths only;
- no prompt, seed, legal note, review note, creator/credit field, or absolute local path.

## Flag-Off Equivalence Tests

Step 11B must prove flag-off behavior is unchanged. Minimum test intent:

- parser/config default returns disabled;
- runtime canary branch is not entered when the flag is absent;
- existing default canary / generation behavior does not require the small fixture;
- no large library path is read;
- no resolver decision, production/default asset pack, QA aggregation, Workbench, or Phaser default path changes.

## Flag-On Canary Tests

Step 11B must prove flag-on behavior is isolated. Minimum test intent:

- `ASSET_RUNTIME_METADATA_CANARY=small-library-v0.1` accepts only the small fixture runtime-safe export;
- invalid or malformed runtime metadata fails closed;
- metadata is read-only and not mutated;
- diagnostics are deterministic and contain no machine-specific absolute paths;
- repair remains disabled unless separately and explicitly enabled by the existing repair controls.

## Rollback

Rollback for Step 11B must be removing or disabling the non-default flag path. Because the flag is off by default, rollback must not require changing production/default runtime configuration.

## Step 11B Candidate File Scope

Step 11B must start by re-scanning current code and may only widen this scope if the scan proves it is necessary:

- new or existing canary option/config parsing module under `scripts/` or `packages/asset-pipeline/src/`;
- focused contract tests under `tests/contracts/`;
- this rollout docs directory and the existing review log.

Step 11B must not edit default Phaser templates, Workbench UI, QA status aggregation, production asset pack loading, `resolveLocalAssetPack`, `selectLocalAssetPack`, or large-library files.
